# Stars and eclipses

[PartialStellarEclipse](partial_eclipse.py) shows two equally sized, equally bright
unit-radius stars. The foreground star is opaque; both surfaces have uniform
brightness. With impact parameter 1, normalized total flux is
`F(s) = 1 - A(s)/(2π)`, where `A` is the blocked overlap area.

This is an illustrative geometric light curve, without limb darkening or orbital
dynamics. The related [offset-disk convolution](../convolution/offset_circles.py)
shows the same geometry as an area integral.

See the [root README](../README.md#render) for render commands.
